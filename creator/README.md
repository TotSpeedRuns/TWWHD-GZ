# Memfile Creator 0.6

Run `python creator/memfile_creator.py` on Windows with Tkinter available.
For Wii U captures, enter the console's local IP and current Creator profile
number from GZ. Keep only one TCPGecko memory client connected at a time.
The published GUI starts with an empty IP field rather than a private address.

These adapters perform read-only capture. Exporting a checkpoint does not make
it reload-verified or suitable for a route automatically. Original capture
provenance and unsupported-state checks remain in the core.
