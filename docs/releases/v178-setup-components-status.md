# Setup178 component source status

The new setup-usb-v178 component is source-only and independently reproducible
as eight authored ET_REL objects. It preserves USB selected-device and Native
transaction policies while expanding the historical-role catalogue to20 exact
artifact records. The newly historical record is Game176; Native current178
and immediate prior177 remain outside that catalogue.

This source snapshot contains no Setup/game executable, SDK, recipe, profile,
full image integrator or live-memory fixture. The component builder needs only
the included text and the declared PowerPC EABI toolchain/standard C header.
It adds5656 immutable bytes, zero mutable storage/imports and no per-frame work.

Prior source and bounded serialized tests are summarized in the component's
VALIDATION.json. They establish narrow compatibility/device/role behavior;
physical USB installation, firmware, Game Save/Restore and lag improvement
remain unverified. This is an added component snapshot; older source folders
and their historical provenance are retained.
