# Detached common process-registry capsule

This freestanding authored C component builds, validates and compares immutable
detached byte views of complete ordered layer, actor, line and draw graphs.
Native addresses are opaque numeric labels. No input points directly into a
live game under this contract; callers must first qualify and copy real views.
It makes no native call, follows no native object and has no apply entry.

The image uses ordinal array references and retains exact PO/HL identities and
native-prefix bytes. Empty descriptors must be represented; pending create,
delete, priority and layer-cancel work is explicitly unsupported in this first
retained lane. Caps refuse rather than truncate. Comparison requires the same
complete retained graph and identities; it neither reconstructs births nor
rewinds observer/allocation serials. The graph checks have bounded quadratic
parts and no measured native performance claim.

The image's `ready` word means completed format publication only. Its missing
mask stays 63, and `grc_read_ready` always returns zero. A valid packet or test
fixture cannot issue ownership. Real current root/line/draw extents, coherent
worker/physical/resource exclusion, immutable source and independent current
undo, external collision/device/audio/message effects, apply and rollback are
still required before any native recovery integration.

The component passed 74 emitted PPC format cases. Independent review reproduced
the selected object exactly and added 48 emitted detached-data cases at two
placements, checking buffer extents, alias refusals, arithmetic, graph/identity
refusals and the unconditional no-readiness result. These are parser/format
checks, not successful native capture or restoration. Source pointers in the
fixtures are not native ownership certificates.

No native provider or main integration is included. This partial component does
not replace the reproducible v126 export.
