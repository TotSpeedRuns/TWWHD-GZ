# Current item lifetime recovery

This is an authored partial C source snapshot for the upcoming v149 test.
It is not a complete current-runtime builder; the complete reproducible export
remains v126. The original translation units, real job/heap/source owners and
typed restore participants are required. No successful owner or native API
provider may be substituted with a fixture.

The consumer arms a bounded retirement intent only after a real typed restore
has failed and its source-free inverse has completed. A separate native writer
revalidates the current item identities, allocations, layer and resource shape,
requests ordinary native deletion once, and observes the normal engine's
retirement metadata. It does not follow old actor storage after scheduling.
A later independently requested restore must reacquire and validate CURRENT.
Completing retirement alone does not mean a saved world was restored.

This experiment is restricted to the explicitly checked native ItemNo1 shape.
It does not add arbitrary actor deletion, broad enemy reconstruction, raw RAM
replay, cross-area restoration, resource/device closure or universal cutscene
support. The separate provider and all existing admission guards remain.

The retained topology borrower uses a real enclosing transaction context and
fixed private workspace. The new item checks distinguish historical birth
state zero from current initialized state two. Three native method comparisons
use the original relocation symbol's TEXT base 0x02000000, rather than the
first instruction section address 0x02000020.

The component was rebuilt after reproducing its entire parent object first.
Only those three native method operands changed in this correction; it adds
no imports, actor masks, memory reserve or blanket coverage permission.
These source and machine checks do not establish Wii U or full-game reliability.
Native qualification and delivery are separate from this source publication.

The files contain authored C, headers and includes only. No game executable,
artwork, original native method bytes, captured game state, save, personal
profile, keys, SDK binary or host memory client is included.
