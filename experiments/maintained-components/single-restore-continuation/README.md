# Experimental single-action quiet-item Restore continuation

This authored C snapshot keeps one ordinary Restore action pending through the
existing finite current-only item retirement, then issues one fresh ordinary
world transaction internally. Two finite Cemu cases passed: two naturally born
quiet HEART0 actors and, separately, three naturally born quiet green rupees (ItemNo 1).
Each used one chooser confirmation, native retirement of the original actor
generations, and an internal fresh request that committed with status 15.

The complete reproducible integrated export remains v126. This is a partial
maintained-source experiment, not a standalone current-runtime builder, console
release, or general save-state qualification. It extends the previously
exported quiet0/1 lifetime consumer without admitting another actor class.

## What changed

The original failed world attempt must complete its typed inverse with CLEAN40
and match the private original commit blocker before the continuation binds.
It does not treat any generic refusal or progress report as retirement authority.
The existing at-most-eight quiet profile 255, ItemNo 0 or 1 checks, original native
delete call, live generations, resource shape and four absent-effect fields are
retained. Actor pointers are not followed after native deletion is scheduled.

A 56-byte separately sealed logical SOURCE receipt reserves the exact slot,
identity, generation, used length and hash. It preserves the public Owner/Row
layout and saved format. It contains no RAW source pointer, physical lease,
thread, heap ticket or job token. Existing allocation/write/publication
boundaries reject changes to the reserved row, and callback beforeimages include
the receipt. The ordinary source-reader busy guard gains the continuation term;
the original guards remain.

An 88-byte continuation, 4-byte reentry word and 12-byte private blocker add 104
bytes of BSS. The SOURCE receipt adds 56 initialized DATA bytes. The adapter adds
no state. Total new private state is 160 bytes; the observed linked DATA range
grew 192 bytes with alignment. Actual private LRW queries prove its physical
HG/job ownership is released; public reports do not supply that proof.

After the genuine original-generation process/collider/SOLID receipts complete,
the same native dispatcher callback queues one fresh request and commit ticket.
The normal native ingress, new frame, owner, source lease and job admission run
again. The original RAW pin, world token and job ticket are not carried across.
The journal keeps the old token value only for commit correlation; it does
not retain that physical capability. There is no choose-again call or host retry. Success is published only after the
second real transaction commits; an intermediate CLEAN40 is kept internal.

Selection, scene, loading, event, resume, SOURCE mismatch and a finite native
frame deadline cancel continuation. An unissued cancellation needs actual
physical quiescence. After an issue, cancellation stops new issues and waits
only on bounded original-generation metadata. A post-issue unknown or timeout
retains private state and its SOURCE receipt. Producer release alone cannot
prove an actor retired. Valid terminal paths release the exact logical receipt
before clearing continuation state and publishing a terminal status; a failed
release never becomes a successful terminal result.

## Finite native results

| Cemu case | Current-only cohort | Observed product flow |
| --- | --- | --- |
| HEART | Two quiet ItemNo0 actors | One chooser/A, original request2 CLEAN40, native retirement mask3, internal request3 commit15 |
| Green control | Three quiet ItemNo1 actors | One chooser/A, original request4 CLEAN40, native retirement mask7, internal request5 commit15 |
| Mixed setup | No complete mixed cohort qualified | Fresh SOURCE14; ordinary current-HP edit and original Heart retention observed; no Restore requested |

The HEART and green observed Restore intervals were approximately 2.96 and 3.01
seconds. Their fresh Save14 intervals were approximately 0.235 and 0.234 seconds.
These are case observations on Cemu, not Wii U timings or a general benchmark.
The earlier manual-retry experiment is separate: these passed cases use one
human confirmation and the runtime itself performs the second fresh request.

The terminal private intent seals the original PO64 and SOLID64 beforeimages,
CO identity/index/owner tuples, original generations, finite ItemNo tuple and
complete scheduled/retired masks. The actual private LRW nonce/serial ended
with physical tokens released. WCC/reentry/blocker cleared, the logical SOURCE
serial advanced once and its receipt released, all 11 checked cleanup blocks
were zero, and original owner/pin/HG/job contexts were clean. Saved SOURCE
bytes, health, sword state and queue were retained or restored by the executed
checks. Six original/disposable save files kept their hashes. Writes were
limited to the three ordinary controller-input spans. No SDK budget fixture,
host actor write, native-result fixture or ownership stub was used.

Normal confirmation release remained enabled; host snapshots are non-atomic.
Progress words corroborate private receipts and are never runtime grants.
A separate read-only green check reported all 1,500 grass rows' 64-byte numeric
spans equal to SOURCE, retaining current live linkage words. The independent
outcome peer did not attach a second live client to repeat that observation.

The mixed attempts are inconclusive before any Restore. In the final setup
attempt an ordinary GZ health operation changed current HP 11 to 12 while the
saved SOURCE retained HP 11, its exact identity and hash, and the original Heart
actor/PID/generation remained in a fresh paused census. Nearby uncut grass then
exhausted before a green cohort formed. This establishes neither mixed Restore
success nor a mixed lifecycle failure. Separate HEART and green passes must
not be presented as a mixed-cohort result. Setup iteration stopped there.

## Source and limits

The 32 baseline/candidate C/header/include files and their exact patch cover the
18 changed or added authored files across the world/menu consumer, SOURCE
logical owner and existing native writer adapter. Authored source text is preserved; one baseline file's CRLF endings
are normalized to LF. Unchanged project dependencies, native bindings and complete
integrated build machinery are not supplied. The private main retained 77 other
roles, all 803 checkpoint payloads, 316 hooks and 365 native imports. Final layout
and finite native queue bindings were checked separately.

This packet includes authored source and hash-only metadata. It contains no
executables, objects, ROM data, resources, artwork, fonts, SDK binaries, saves,
captured state, host profiles, controller clients, native RAM dumps or captured
addresses. Existing authored native boundary constants and anchor-relative
guards are retained as code; no live profile addresses are exported. The
repository root MIT license applies to this authored source.

Active item effects, arbitrary actors, missing ownership providers, general
reconstruction, collection semantics, cross-area and cutscene replay, boss and
particle closure, Wii U behavior and full-game save states remain unsupported
or unqualified. The existing smoke/effect coverage refusal remains. No future
smoke, FXB2 or broader constructor source is merged. Cancellation and retained
failure branches have source checks, not exhaustive native coverage.

Before publication, verify the explicit file hashes and run the repository
source audit and portable publication tests. Keep these limits and case counts
in any status or release description. This proposal does not publish a build.

Portable metadata tests exercise the actual exported SOURCE policy header,
including corruption, stale receipts, other-slot writes and serial exhaustion.
They supply no native or world-restore authority.
